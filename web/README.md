# 深蓝漫游 · 原生 WebGL2 高保真深海

零依赖、零 CDN、零纹理素材的实时深海漫游。几何、材质、水波、焦散、微粒、光柱与后期全部程序化生成；不使用 three.js，也不需要构建工具。旧版完整保留在 `../web_legacy/`。

## 启动

- 直接双击 `index.html`，普通 `<script src>` 支持 `file://`。
- 或运行：

```bash
cd web
./serve.sh                 # http://127.0.0.1:8766
./serve.sh 8080            # 指定其他端口
```

### 画质档定位

| 档位 | 分辨率策略 | MSAA / 颜色目标 | 材质与用途 |
| --- | --- | --- | --- |
| 电影 | 标准 DPI 为原生 1.0；高 DPI 上限 **1.75** | 优先 **8× 浮点 HDR** | 完整微表面、粗糙法线、虹彩、焦散和 Bloom；不自动降清晰度，适合截图与高端 GPU |
| 高 | 原生分辨率，标准 DPI 为 **1.0** | **4× RGBA8** | 保留腹背层次、鳞片、GGX、鱼鳍透光与沙地焦散；减少重复微表面采样，面向流畅 1080p |
| 流畅 | DPR **0.75** | 2× RGBA8 | 降低海面、微粒和后期开销 |
| 自动 | DPR 0.65–1.25 | 按质量动态选择样本数 | 根据平滑帧率逐级调整 |

电影档是否得到 8× 浮点 MSAA 取决于硬件；本机实测支持。若浮点多样本目标不可用，会查询并回退 RGBA8 多样本目标。样本数、DPR 与实际 canvas 尺寸可通过 `window.__app.renderer` 检查。

## 为什么旧版有锯齿，现在如何处理

旧版虽然使用 WebGL2，但场景先画进单样本离屏 FBO，默认 framebuffer 的 AA 无法作用于海豚、鱼鳍和海藻，放大后就会出现阶梯。

当前管线：

1. 场景渲染到 **多样本 color/depth renderbuffer**。
2. 使用 `blitFramebuffer(..., NEAREST)` 做多样本 resolve 到场景纹理。
3. 亮度提取、1/4 分辨率柔和 Bloom、ACES 色调映射到 LDR。
4. 最后一遍亮度导向 **FXAA** 清理剩余边缘；不叠加锐化，也不靠降低分辨率遮盖轮廓。

高/电影档的截图均为 1920×1080 原生渲染。FXAA 只是最后保险，主要几何边缘改善来自真实 MSAA。

## 高保真材质

- **海豚**：自然腹背过渡、低频体色、克制毛孔与水痕、稀疏细伤痕、粗糙度变化、GGX 高光、湿润 Fresnel 与轻微水下透光。完整微细节在电影档执行。
- **鱼体**：提高轮廓细分和横向厚度，平滑法线、腹背颜色、鳞片变化、视角相关虹彩；更薄的曲线鱼鳍带透光，仍为每种鱼一次实例化绘制。
- **海底**：分层沙纹/颗粒，法线扰动随距离衰减；`fwidth` 和屏幕足迹控制高频细节，降低闪烁。焦散采用两层不同频率、旋转和相位的边界亮丝网络，domain warp 打散网格感，大尺度层只调制亮度，远距通过 `fwidth` 淡出。
- **礁石**：多尺度颜色层理、粗糙法线和低强度高粗糙度反射。
- **海藻**：每片叶子的长度、宽度、扭转与弯曲不同，保留实例化顶点摆动。
- **后期**：降低硬高光与 Bloom 强度，保留局部材质，不做全局磨皮或锐化。

## 场景与远场

- 4 组 Gerstner 波、双层 Voronoi 边界亮丝焦散、深度/高度指数海雾、14 束低成本 billboard 光柱。
- 1 只主角海豚 + 3 只远豚；主角在闭环 0.74 附近伴游并侧前方掠过，全循环最近中心距离约 **3.289 米**。
- 72 条沙丁鱼、48 条黄色礁鱼、36 条高体鱼，共 156 条实例化鱼。
- 192 株海藻、64 块礁石、48 株珊瑚、1600 个微粒，生态数量不变。
- 600 米非线性海床、800 米水面、500 米远裁剪面。
- 天空、海床、水面与物体共享 `oceanBackground(ray)` 和 `waterFog()`，避免有限网格边界形成深色带。


## 解剖、泳姿与近距遭遇

### 瓶鼻海豚结构

`geometry.js` 使用 72 环 × 28 点的改进放样，成年主角约 3.2 米：胸段浑圆、尾柄侧扁收窄，额隆仅小幅隆起；短吻约占体长 6%，上下颌分别成形。吻部与额隆/头部使用同一连续放样曲面，口角仅为浅灰细曲线；眼睛缩小并后移至吻根，采用深蓝灰材质。背鳍为后弯镰形，胸鳍为后掠桨状并缩减约 19% 面积。尾鳍采用一个连续轮廓形成水平两叶、中央缺刻和内凹后缘，展宽约为体长 22%。

### 生物运动

- 海豚仅使用 **dorsoventral 垂直摆尾**，振幅向尾部递增，头部区域权重为零；频率随路径/遭遇速度平滑变化，不再有横向蛇形扭动。
- 鱼类使用 **lateral 水平摆尾**，三种鱼有不同频率、行波相位和摆幅，小鱼频率更高。
- 海豚朝向由路径切线构建，以上方向为稳定参考系，转弯时产生受限且阻尼平滑的 bank/roll，避免参考系翻转。
- 鱼群使用非等速旋涡流场、个体扰动、两个近邻的分离与方向扰动；仍保持每种鱼一次实例化绘制。

### 镜头编排

`scene.js` 的 `DOLPHIN_EVENT` 与 `FISH_EVENTS` 定义相机相对的安全遭遇走廊，并使用平滑窗口与原闭环路径混合：

- **主角伴游**：相位 0.74，持续 **11.16 秒**；先侧向伴游，再从侧前方掠过。峰值 gaze 准确偏向海豚，离开后回到海底/水面目标，航速同步平滑减慢。
- **鱼群穿越一**：相位 0.26，持续 **9.33 秒**，8 条近距银蓝鱼从侧前方通过。
- **鱼群穿越二**：相位 0.56，持续 **10.00 秒**，8 条黄色礁鱼形成包围层次。
- 全循环采样记录：主角最近 **3.289 米**，鱼最近 **1.866 米**；动物 Y 范围约 **-4.61–7.13 米**，均处于海床上方和水面下方的安全水层。
- 对整个闭环的 8 个相位另做接触表目检，检查近景遮挡、路径连续性和翻滚情况。

近距鱼使用较小的个体实例，不让鱼体遮满镜头；前景遭遇个体与中远景群游仍来自同一实例 buffer。


## 多物种生态与独立行为

本次在保留海豚、三类鱼群和既有近距遭遇的基础上，新增 **6 类、27 只动物**。场景现共 10 类动物、187 个动物个体（不含海藻）。当前质量版本另备份于 `web_prev_quality/`。

| 新物种 | 数量 | 解剖与材质 | 独立动画 | 近景事件 / 最近距离 |
| --- | ---: | --- | --- | --- |
| 绿海龟 | 2 | 流线龟壳、盾片分区、头颈、前后桨肢和短尾 | 前肢上下划水，后肢小幅配合 | 相位 0.12 / **3.288 m** |
| 蝠鲼 | 2 | 扁平连续翼盘、前侧头鳍、肩隆和细长尾 | 左右扇翼，翼尖相位延迟 | 相位 0.36 / **4.997 m** |
| 鲸鲨 | 1 | 宽头细口裂、粗壮长身、窄尾柄、自然抖动斑点 | 慢速垂直摆尾 | 相位 0.84 / **11.792 m** |
| 水母 | 10 | 内外伞面、放射纹、4 条口腕和 12 根触手 | 伞体脉冲、触手滞后拖尾；普通 alpha 混合 | 相位 0.46 / **2.115 m** |
| 狮子鱼 | 4 | 条纹、分离背鳍棘、鳍条和半透明扇膜 | 悬停小幅扇鳍 | 相位 0.64 / **2.472 m** |
| 螃蟹 | 8 | 头胸甲、8 条步行足、双螯和分节腿 | 海底横行、交替步态 | 相位 0.94 / **1.877 m** |

新动物由 `animals.js` 的程序化厚实体几何生成，全部使用平滑法线和独立材质。海龟壳盾片、鲸鲨斑点和水母放射纹均由 shader 生成，无外部纹理。每种动物共享一个实例 buffer；海龟/蝠鲼/鲸鲨/螃蟹等重复个体不会逐只增加 drawcall。

近景事件与海豚伴游、两处鱼群穿越错相安排，避免同一帧把所有动物堆到镜头前。螃蟹事件使用独立的海底相机下沉和 gaze；其他事件使用相机相对安全走廊，离开后平滑回到原路径。`ANIMALS.EVENTS` 是调参入口。

### 全循环验证

- 对完整闭环进行 1201 个相位采样，并另拍 8 个相位的接触表。
- 所有实例位置、朝向均为有限值，方向向量保持归一化；未发现突然翻滚。
- 新动物 Y 范围约 **-9.04–8.00 m**，位于海床与水面之间。
- 视频与近景图已检查划肢、扇翼、脉冲和透明层次；未使用 billboard 动物轮廓。
- 浏览器控制台、未捕获异常和 WebGL 错误均为 0。

## 调参与调试

| 目标 | 位置 |
| --- | --- |
| MSAA、resolve、Bloom、LDR/FXAA | `js/renderer.js` |
| FXAA 过滤 | `js/shaders.js` 的 `fxaaFS` |
| 海豚 / 鱼 / 礁石材质 | `dolphinFS`、`fishFS`、`objectFS` |
| 沙地过滤与法线 | `terrainFS`、`perturbNormal()` |
| 几何细分和曲线鳍 | `js/geometry.js` |
| 画质 DPR、样本数、自动策略 | `js/main.js` 的 `setQuality()` / `adapt()` |
| 相机和生态布局 | `js/scene.js` |

`window.__app.scene.animals` 可检查六类实例数据；`window.ANIMALS` 暴露几何/行为模块。`window.__app` 暴露 `scene`、`renderer`、`camera`、`state` 和 `setQuality()`。当前版本不包含路径追踪、体积步进或外部纹理，微表面主要由程序化 shader 而非真实位移几何产生。群游采用轻量近邻扰动而非完整流体力学；遭遇使用经过全循环采样的安全走廊，不包含通用刚体/礁石碰撞求解器。水母采用实例级普通透明混合而非逐触手深度排序；所有新物种仍为程序化近似解剖，而非扫描级模型。
