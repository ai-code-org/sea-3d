# 深蓝漫游 · 原生 WebGL2 深海

零依赖、零 CDN、零纹理素材的实时深海漫游。几何、材质、水波、焦散、微粒、光柱与后期全部程序化生成；不使用 three.js，也不需要构建工具。

旧版已完整复制到 `../web_legacy/`，本目录是重制版。

## 启动

### 直接打开

双击 `index.html`。全部脚本使用普通 `<script src>`，已在 Chrome 的 `file://` 环境验证，不需要 ES Module 或跨域资源。

### 本地服务器

```bash
cd web
./serve.sh                 # http://127.0.0.1:8766
./serve.sh 8080            # 也可指定端口
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 自动漫游 | 默认开启，120 秒闭环；相机位置和注视目标分别沿闭合 Catmull-Rom 曲线运动 |
| 鼠标 / 触控拖拽 | 平滑环视，偏航与俯仰使用指数阻尼 |
| 滚轮 | 调整目标航速，实际航速平滑跟随，不会跳变 |
| 空格 /「暂停漫游」 | 暂停或继续相机路径；海豚、鱼群、水波仍继续运动 |
| R /「视角重置」 | 平滑复位拖拽视角和航速，不重置漫游相位，避免镜头瞬移 |
| 航速滑杆 / `+` / `-` | 0.35×–2.00× 调速 |
| 「画质」 | 依次切换自动、高、中、低 |
| 相机按钮 | 将当前 WebGL 画面保存为 PNG |
| H | 隐藏 / 显示 HUD，适合观赏和截图 |

## 场景内容

- **海面**：4 组 Gerstner 波叠加，高频微法线、水下 Snell 窗口、太阳高光与 glitter。
- **海水**：距离雾和水下高度吸收，蓝青深度渐变，1600 个程序化悬浮微粒。
- **焦散**：两层动态 Voronoi + fbm 扭曲，同时作用于沙地、生物与礁石。
- **光柱**：14 个面向相机的实例化 billboard，带纵向柔化、距离衰减和深度遮挡，无体积步进。
- **海豚**：1 只主角 + 3 只远豚；放样身体、背鳍、胸鳍、水平尾鳍和眼睛，各自沿闭合曲线游动，顶点着色器行波摆尾。主角在漫游约 79% 处侧向近掠，整个循环最小中心距离约 11.30 米，背鳍和尾鳍保持完整入镜。
- **鱼群**：72 条银蓝沙丁鱼、48 条黄色礁鱼、36 条高体热带鱼；每种一次 instanced draw call，沙丁鱼群具有旋涡编队。
- **海底**：600 米非线性细分程序化 fbm 沙地、细沙/沙纹 shader、64 块礁石、48 株分枝珊瑚。
- **海藻**：192 株，一次实例化绘制，顶点着色器双流场摆动。
- **后期**：HDR（支持时）→ 亮度提取 → 1/4 分辨率双向模糊 → ACES、暗角和轻颗粒。

## 性能与自适应

2026-11-19 本机实测：

- Chrome / ANGLE Metal / **Intel Iris Plus Graphics**
- 1920×1080，高画质，DPR 1.0
- 起始、仰视和近景掠过三个检查点均 **平均 60.00 FPS**，P95 **16.7–16.8 ms**
- 高画质总绘制调用约 **19 次**（含后期）
- WebGL 错误码 `0`，无 shader 编译、控制台或未捕获异常

自动模式每约 2.4 秒评估一次平滑帧率：

1. 低于 43 FPS 时先逐级降低 DPR，最低 0.65。
2. DPR 已较低时降低质量档：减少海面细分（88 → 56 → 32）、微粒（1600 → 1000 → 500），再关闭 Bloom。
3. 持续高于 57 FPS 才逐步恢复质量和 DPR，上限 1.25，避免频繁来回切换。

远雾区跳过不可见的沙地细节和焦散计算；鱼群实例数据复用固定 `Float32Array`，每帧只更新已有 buffer；相机、海豚矩阵和路径采样向量均预分配。

> 不同 GPU、浏览器后台策略和显示器刷新率会影响实测值。无浮点颜色缓冲扩展时自动回退 RGBA8，场景仍可运行。

### 远景边界修复

旧版天空使用独立渐变，而物体雾色按世界高度计算，且雾量被限制在 94%，导致有限海床与水面边缘无法融入背景。现在天空、海床、水面和物体统一使用 `oceanBackground(ray)` 与指数 `waterFog()`；600 米海床和 800 米水面采用近密远疏的非线性网格，边缘在雾中已接近完全透明，远裁剪面扩展至 500 米。
